# Project Overview

## Capabilities
- CSV upload + demo dataset loading
- Feature engineering (ratios, engagement, activity score)
- Behavioral scoring with risk levels
- Graph analysis + bot-ring detection (if relations exist)
- ML detection (RandomForest / IsolationForest)
- Explainable AI reasons per account
- Fake probability + trust score + report summaries
- Interactive dashboard (risk breakdown, charts)
- Multi-language UI (FA/EN/AR)
- Admin + Bot Admin panels (secured login)
- Telegram bot with group detection and admin controls
